# MtbLongitudinalDiversity

Analysis of longitudinal changes in <i>Mycobacterium tuberculosis (Mtb)</i> genetic diversity during the course of tuberculosis infection and treatment in the TRUST cohort.

The goals of this project are to

<ul>
  <li>Build a robust pipeline to call unfixed single nucleotide variants (SNVs) and indels in <i>M. tuberculosis</i> clinical samples </li>
  <li>Identify changes in unfixed variants (i.e., unfixed to fixed, unfixed to absent) across longitudinal clinical samples</li>
  <li>Determine if a greater number of unfixed variants at baseline is associated with worse patient treatment outcomes. Greater unfixed variants may suggest increase bacterial fitness.</li>
</ul>
